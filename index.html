GNSS (Global Navigation Satellite System)

Global Navigation Satellite System (GNSS) is the umbrella term for satellite constellations that provide autonomous geo-spatial positioning with global coverage. Standard GNSS positioning uses triangulation from at least four satellites to solve for latitude, longitude, altitude, and receiver clock bias.

Key Satellite Constellations

  • GPS (United States): Navstar system operating on L1 (1575.42 MHz), L2 (1227.60 MHz), and L5 (1176.45 MHz) carrier waves.
  • GLONASS (Russia): Mapped on FDMA (Frequency Division) and newer CDMA channels.
  • Galileo (European Union): Highly precise civilian-controlled system using E1, E5a, E5b, and E6 signals.
  • BeiDou (China): Chinese satellite constellation deploying B1, B2, and B3 frequencies.
  • Regional Systems: Includes QZSS (Japan) and IRNSS/NavIC (India) providing focused regional coverage.

GNSS Error Sources

Standard GNSS is prone to several errors that limit accuracy to 2–5 meters:

  1. Atmospheric Delays: Ionospheric scintillation and tropospheric water vapor slow down satellite signals.
  2. Multipath Interference: Signals bounce off buildings, trees, or the ground before hitting the receiver antenna.
  3. Ephemeris & Clock Errors: Minor drift in satellite atomic clocks or calculated orbit paths.

GEODNET stations monitor these atmospheric and orbital drifts dynamically, enabling the correction engine to subtract them.

RTK (Real-Time Kinematic)

Real-Time Kinematic (RTK) is a differential GNSS technique that improves positioning accuracy to centimeter-level. While standard GNSS measures the arrival time of the satellite code (pseudorange), RTK measures the phase of the carrier signal wave, which has a wavelength of about 19 centimeters.

Double-Differencing Technique

RTK relies on a static base station with known coordinates and a moving rover. By subtracting base station measurements from rover measurements (double-differencing), common errors like satellite clock drift, ephemeris bias, and atmospheric delays are mathematically canceled out.

Carrier-Phase Ambiguity: Float vs. Fix

  • RTK Float: The receiver is calculating the integer number of wavelengths between the satellite and the antenna. At this stage, accuracy is decimeter-level (10–50 cm).
  • RTK Fix: The RTK algorithm resolves the carrier-phase ambiguity. The exact integer number of cycles is locked. The position shifts to centimeter-level accuracy (1–2 cm).

Baseline Limitation

Because atmospheric characteristics change over distance, the cancellation of errors decreases as the baseline (distance between base and rover) increases. Standard single-base RTK baseline is limited to about 20–30 km. GEODNET resolves this by providing a dense grid of base stations, facilitating short baselines globally.

NTRIP (Networked Transport of RTCM via Internet Protocol)

NTRIP stands for Networked Transport of RTCM via Internet Protocol. It is an application-level protocol designed for streaming differential GNSS corrections over mobile internet connections (cellular, Wi-Fi).

NTRIP Architecture Components

  1. NTRIP Source: The GNSS base station (e.g. GEODNET receiver) which records satellite phase data and generates RTCM correction streams.
  2. NTRIP Server: The transfer agent that pushes the RTCM data from the source to the caster.
  3. NTRIP Caster: An internet server acting as an HTTP proxy. It manages user logins, holds a "Source Table" listing all available streams (mountpoints), and broadcasts corrections. GEODNET's main caster is located at rtk.geodnet.com.
  4. NTRIP Client: The GNSS rover receiver (or autopilot software) that logs in to the caster, selects a mountpoint, and receives the RTCM correction stream.

NMEA GGA Upload Requirement

For smart casters (like GEODNET's AUTO mountpoint), the NTRIP client must upload its approximate position using an NMEA GGA string. The caster uses this location to select the closest base station or compute virtual correction data for the client's position.

RTCM Messages & Message Structure

The Radio Technical Commission for Maritime Services (RTCM) defines the standard binary protocols for differential GNSS correction messages. The most widely used format is RTCM v3.2, which utilizes Multiple Signal Messages (MSM) to deliver full-constellation, multi-frequency carrier phase data.

Geodetic Coordinate Systems

A Geodetic Coordinate System is a coordinate system used to locate points on the Earth's surface using latitude, longitude, and ellipsoidal height. It consists of a reference ellipsoid and a datum (datum defines the position and orientation of the ellipsoid relative to the Earth's center).

Global Datums vs. Tectonic Plates

The Earth is composed of moving tectonic plates. Because of this, we have two types of coordinate frames:

  • Global Dynamic Frames (e.g., ITRF2020, WGS84): These coordinates are Earth-Centered, Earth-Fixed (ECEF) and are anchored to the center of mass of the Earth. A physical base station's coordinates in ITRF will drift by 1–5 cm per year as its tectonic plate moves.
  • Regional Static Frames (e.g., NAD83 in USA, ETRS89 in Europe): These datums are locked to a specific tectonic plate. In the US, coordinates in NAD83 do not shift over time for local physical objects because the ellipsoid moves along with the North American plate.

The Role of Epochs

An epoch specifies the exact point in time a coordinate was recorded (e.g., Epoch 2010.0). Since global datums are dynamic, a coordinate is only complete if it specifies both the datum and the epoch (e.g., ITRF2014 at epoch 2026.35).

Projected Coordinate Systems

While geodetic coordinates represent points on a three-dimensional curved surface (ellipsoid), surveying and engineering drawings require a flat, two-dimensional surface. A Projected Coordinate System (PCS) projects ellipsoidal latitude and longitude coordinates onto a flat grid using plane coordinates (Northing and Easting, or X and Y).

Common Map Projections

  1. Universal Transverse Mercator (UTM): Divides the Earth into 60 zones, each 6 degrees of longitude wide. It uses a conformal cylinder projection to minimize distortion of angles and shapes within each zone.
  2. State Plane Coordinate System (SPCS): A local coordinate system used in the United States to reduce scale distortions in engineering. Individual states are divided into zones based on Lambert Conformal Conic or Transverse Mercator projections.

RTK Mapping Workflows

A typical surveying workflow involves receiving centimeter-accurate coordinates in a geodetic datum (via the GEODNET AUTO mountpoint), and then using a rover field controller (e.g., CAD/GIS software) to perform a coordinate projection into the local UTM grid or State Plane zone for building and construction designs.
